🚀 部署流程(30-40 分钟)

  1. 解压 zip:unzip tianjishu-netlify-pack.zip
  2. 注册/登录 GitHub → 创建 tianjishu-a 仓库 → 生成 Personal Access Token(勾 repo + workflow)
  3. 在解压目录里跑: 
    git init
git add . && git commit -m "首发"
git branch -M main
git remote add origin https://用户名:TOKEN@github.com/用户名/tianjishu-a.git
git push -u origin main
  4. 登录 app.netlify.com → Add new site → Import GitHub 仓库 → Deploy
  5. 启用 GitHub Actions:
    仓库 → Settings → Actions → General → Workflow permissions 改成 Read and write
  6. Actions 标签 → 选 "每日抓 A 股 + 盘前数据" → 手动 Run workflow 测试一次
  7. 绑阿里云域名(可选,详见 GITHUB_NETLIFY_GUIDE.md §4)
